# Tienda de Videojuegos Online

## Descripción

Tienda de videojuegos desarrollada como proyecto universitario utilizando React. La aplicación permite explorar un catálogo de juegos, visualizar sus detalles, filtrar por categorías, buscar títulos específicos, gestionar un carrito de compras y acceder a una biblioteca personal de juegos adquiridos.

Además, cuenta con páginas de contacto, información del equipo de desarrollo y un sistema de autenticación para la navegación dentro de la aplicación.

---

## Tecnologías utilizadas

- React 19
- React Router DOM
- Vite
- Bootstrap 5
- React Bootstrap
- React Icons
- CSS3
- JavaScript

---

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/Franco2912/tienda-videojuego-online-react.git
```

### 2. Acceder al directorio del proyecto

```bash
cd tienda-videojuego-online-react
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el proyecto en modo desarrollo

```bash
npm run dev
```

### 5. Abrir en el navegador

Vite mostrará una URL similar a:

```text
http://localhost:5173
```

Abrir dicha dirección en el navegador.

## ✨ Funcionalidades principales

- Catálogo de videojuegos.
- Búsqueda de juegos por nombre.
- Filtrado por categorías.
- Vista detallada de cada juego.
- Carrusel de juegos destacados y en promoción.
- Galería multimedia.
- Carrito de compras.
- Biblioteca de juegos adquiridos.
- Formulario de contacto.
- Página institucional del equipo.
- Manejo de rutas con React Router.
- Página personalizada de error 404.
